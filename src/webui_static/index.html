ℹ️ QQ 官方 Bot 填写与 OpenID 自动获取说明
• App ID 与 Secret：App ID 直接在表格里填；Client Secret 点对应行「填写」存入 .env。
• 多目标路由推送（同一 Bot 推多群）：同一个 QQ 官方 Bot（相同 App ID & Secret）可添加多行，分别填写不同的【群 OPENID】或【个人 OPENID】，并配置独立的【⚙️ 订阅规则】（如群 A 订阅日向坂、群 B 订阅乃木坂），相互独立、互不干扰。
• 指令监听去重：若启用「私聊 Bot 查询信息」，系统会自动对相同 App ID 聚合复用单个 WebSocket 连接，绝不重复连接或冲突。
• 目标 OpenID 获取：已知可直接填；不知则点「🎯 自动获取」，向 Bot 发送一条私聊消息即可自动捕获回填。
